# School Canon — Архитектура школы управленческого мышления

**Статус:** начальный центральный канон школы; архитектура уточняется по мере интеграции исходного корпуса, новых методологических разработок и результатов исследований.  
**Назначение репозитория:** собрать в одном месте целостную архитектуру школы мышления, сохраняя преемственность между исходным корпусом, образовательной методологией и научными контурами.

## North Star

> **Экономика — среда. Модель — инструмент. Мышление — результат.**

Базовая связка:

`реальность → знак → модель → действие → результат → проверка реальностью`

Рабочая расширенная траектория:

`реальность → знак → понятие → логика → онтология → различение → модель → система → количество → метрика → экономика → финансы → процесс → проект → решение → действие → обратная связь`

Эта траектория задаёт архитектуру освоения и дисциплину проверки, но не объявляется буквальной психологической последовательностью мышления.

## Что является исходным основанием

До создания этого репозитория существовал корпус **«Архитектура управленческого мышления. Корпус школы мышления v0.2»**.

Он остаётся исходным архитектурным источником школы. В нём последовательно развиваются:

- логический фундамент;
- когнитивная архитектура управленца;
- модельное мышление и онтология;
- экономическое и финансовое мышление;
- процессное и проектное мышление;
- организация как система моделей;
- данные и метрики;
- ошибки, искажения и «белиберда»;
- образование как воспроизводство мышления;
- когнитивная зрелость.

School Canon не заменяет этот корпус задним числом. Его задача — постепенно сделать общую архитектуру явной, связать старые и новые разработки и фиксировать актуальные согласованные решения.

## Что нового добавляется сейчас

В 2026 году в работе над курсом и научной программой сформировался новый методологический слой.

### 1. Матрица когнитивных переходов

Рабочая гипотеза:

> **каждый значимый переход в предметной модели должен требовать определённой, называемой и проверяемой когнитивной операции.**

Базовая строка:

`предметный переход → тип отношения → когнитивная операция → критерий корректности → типичная ошибка`

### 2. Две согласуемые траектории

Исторически идея возникла как «две параллельные архитектуры», но в строгой версии различаются:

- **предметная траектория** — что меняется в представлении объекта;
- **операциональная траектория** — какое интеллектуальное действие требуется для перехода.

Их связь задаётся матрицей переходов, а не формальным сходством названий.

### 3. Исследовательская архитектура

Для научной проверки добавляется третий слой:

`операция → ожидаемый след → кодируемый признак → данные → проверка гипотезы`

Ключевое ограничение:

> **когнитивная операция ≠ наблюдаемый след операции.**

## Основные различения школы

Не смешивать:

- реальность ≠ знак ≠ модель;
- объект ≠ его характеристика;
- часть–целое ≠ род–вид ≠ класс–экземпляр;
- уровень системы ≠ уровень абстракции;
- ресурс ≠ актив ≠ процесс;
- продукт ≠ эффект ≠ ценность;
- процесс ≠ проект;
- метрика ≠ данные ≠ цель;
- выручка ≠ прибыль ≠ денежный поток;
- решение ≠ действие ≠ результат.

Рабочая формула онтологии:

> **словарь сущностей + структура отношений**

Холархия сохраняется как специальный язык вложенных отношений **часть–целое**, но не применяется ко всем иерархиям.

## Экономика и финансы в школе

Экономика — не только предметный кейс. В исходном корпусе она рассматривается как способ видеть реальность через ограниченность, выбор, альтернативы, ценность, время и последствия действия.

Финансы — количественная операционализация этой экономической реальности.

Принцип:

> **сначала сущность и уровень системы — затем число и метрика.**

## Образование

Школа понимает образование не как передачу готовых интеллектуальных конструкций, а как создание условий, в которых человек сам выполняет необходимые действия мышления.

Педагогический принцип:

> **минимум пассивного объяснения — максимум интеллектуального действия учащегося.**

Рабочая схема:

`предметная проблема → операция → модель / артефакт → критерий → ошибка → перенос → рефлексия`

## Как новая идея попадает в канон

Каждая существенная идея должна получить явный статус и пройти проверку:

1. Какой объект она описывает?
2. Какой тип отношения использует?
3. Как связана с исходным корпусом?
4. Она **заменяет**, **уточняет**, **добавляет слой**, **операционализирует** или только **генерирует гипотезу**?
5. Есть ли логические противоречия с текущей архитектурой?
6. Нужна ли проверка источниками, учебной практикой или эмпирическим исследованием?
7. Какое решение должно быть зафиксировано в School Canon?

Статусы, которые будут использоваться в репозитории:

`CANON / WORKING CANON / HYPOTHESIS / EXPERIMENT / CASE / FROZEN / OPEN / DEPRECATED`
