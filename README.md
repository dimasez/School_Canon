# School Canon — Архитектура школы управленческого мышления

**Статус:** центральный живой канон школы.  
**Назначение:** удерживать согласованную архитектуру Школы управленческого мышления, сохраняя преемственность между исходным корпусом, образовательной практикой, методологическими разработками и научными исследованиями.

## North Star

> **Экономика — среда. Модель — инструмент. Мышление — результат.**

Экономика — основная предметная среда / оптика школы, но не универсальная онтология реальности.

## Две базовые модели

**Эпистемический цикл** — как представление связано с реальностью:

`реальность → знак → модель → проверка реальностью`

**Деятельностный цикл** — как действует субъект:

`субъект + задача + ситуация → граница → различения → модель → решение → действие → результат → обратная связь`

Они не конкурируют: отвечают на разные вопросы.

Каждая другая последовательность в School Canon должна иметь тип: предметная траектория, операциональная траектория, дидактический порядок или архитектурная карта модулей.

## Откуда вырос School Canon

Исходным архитектурным источником остаётся корпус **«Архитектура управленческого мышления. Корпус школы мышления v0.2»**.

Он включает:

- логический фундамент;
- когнитивную архитектуру управленца;
- модельное мышление и онтологию;
- экономику и финансы;
- процессы и проекты;
- организацию как систему моделей;
- данные и метрики;

- образование как воспроизводство мышления;
- когнитивную зрелость.

Новые идеи должны быть явно классифицированы как наследование, уточнение, синтез, операционализация, замена или гипотеза.

## Четыре семейства модулей

Рабочая навигационная таксономия:

- **фундаментальные** — логика, реальность–знак–модель, онтология, системы;
- **предметные** — экономика, финансы, стратегия, BMC, процессы, проекты;
- **методологические** — когнитивные переходы, задания, наблюдаемые следы, операционализация;
- **метамодули** — образование, зрелость, ошибки, ИИ, организация как носитель моделей.

Это не уровни и не строгая MECE-классификация реальности.

## Модуль, чанк, операция

> **Модуль = архитектура знания.**  
> **Чанк = когнитивная упаковка знания.**  
> **Операция = воспроизводимый шаг рассуждения.**

Строго:

> **Когнитивная операция — воспроизводимый интеллектуальный шаг преобразования предметного представления, имеющий вход, тип преобразования и критерий корректности результата.**

Ключевое правило:

> **Чанк может сжимать несколько отношений. Канонический модуль обязан распаковать и типизировать эти отношения.**

Поэтому `продукт → эффект → ценность` может быть хорошим чанком, но не заменяет строгую причинно-оценочную модель.

## Онтология и навигация

В School Canon различаются:

1. онтологические обязательства;
2. предметная онтология;
3. концептуальная схема;
4. формальная онтология.

По умолчанию `онтология` = **предметная онтология**.

> **Онтология ≠ концептуальная схема.**

BMC — концептуальная схема аспектов бизнеса.

Строго различаются оси:

- состав / уровень системы — `целое → часть → компонент`;
- общность — `род → вид`;
- конкретизация — `класс → экземпляр`;
- абстракция — `цель → функция → средство / зачем ↔ как`;
- разрешение — степень детализации модели.

## Два источника когнитивных операций

**Общий структурный слой — WORKING CANON:**

`тип отношения → операция`

Например: часть–целое → декомпозиция.

**Предметно-специфический слой — HYPOTHESIS / RESEARCH-DERIVED:**

`структура категории + репрезентация + практика → специфический операционный профиль`

Эта исследовательская линия связана с `EAG-D-059` и должна проверить, предъявляет ли экономическое содержание специфические требования сверх общих логико-онтологических операций.

## Экономическое ядро

Ключевой принцип:

> **Экономическая категория — статус объекта в определённом отношении.**

Две базовые ветви:

`объект —[отношение к субъекту]→ благо`

`объект —[отношение к системе]→ ресурс / актив`

Ориентационный чанк:

`объект → ресурс → актив → конфигурация → способность → процесс → эффект → ценность`

Это сжатая навигация, а не строгая схема одного отношения.

Не смешивать:

`благо ≠ актив`; `актив ≠ способность`; `способность ≠ процесс`; `продукт ≠ эффект ≠ ценность ≠ цена`.

## Предмет → операция → задача → след

Методологическая связка:

`предметный переход → когнитивная операция → учебная задача → артефакт → наблюдаемый след`

Ключевое ограничение:

> **наблюдаемый след ≠ доказательство самостоятельного мыслительного акта.**

След может возникнуть благодаря учащемуся, команде, преподавателю, шаблону, источнику или ИИ.

Паспорт когнитивно содержательного задания — WORKING CANON. Тезис, что задача является центральным механизмом связи предмета и операции, остаётся HYPOTHESIS.

## Transfer

Текущая доказательная заявка ограничена:

- ближним transfer;
- средним transfer.

Дальний перенос = `HYPOTHESIS / OPEN`.

Фальсификатор:

> **Если учащиеся лучше знают словарь операций, но не лучше решают transfer tasks, заявленный способ мышления не подтверждён.**

## ИИ

> **ИИ — усилитель мышления, а не его замена.**

Критерий присвоения результата:

> **Способен ли человек объяснить, защитить и пересобрать модель, созданную с помощью ИИ?**

## Конечный ориентир

Школа стремится формировать человека, способного видеть реальность, различать сущности и типы отношений, строить модели, понимать системы, измерять существенное, непротиворечиво рассуждать, выбирать, принимать решения, действовать и пересматривать картину мира после обратной связи от реальности.
